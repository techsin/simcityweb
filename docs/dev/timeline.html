      How the dates are worked out

      Every step has an estimate in hours of team work (cloud agents and your desktop together), based on how long similar steps took. Steps in different workstreams run side by side, so the finish date is set by the longest chain: polish, then the final check.

      Work runs around the clock until the weekly usage limit is reached. A weekly window gives about 38 hours of work; the last full one gave about 42 with four cloud agents. Your desktop's Claude worker draws on the same weekly pool; Codex has its own. Restarts and waits add about 8 % to the wall time.

      Estimates for steps that only run if a check finds something serious count toward the worst case, not the likely date. Dates marked ≈ are estimates; everything without ≈ already happened.
